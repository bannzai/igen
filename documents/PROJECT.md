# 偉言 (igen) プロジェクト要件

企画の出典: https://github.com/bannzai/IdeaMemo/issues/180 （需要・競合・命名・UI 要望の一次情報はこの issue のコメント群）

## コンセプト

悩みや今日のできごとを書くと、それに適した偉人が現れて、出典付きの格言・ことわざで励ましてくれる iOS アプリ。チャットではなく「人生相談への返書」フォーマットに振り切る。カウンセリング・セラピーは名乗らない（励まし・自己肯定のエンタメ寄り）。

### Why

- 悩みを書くだけで、同じような境遇を乗り越えた偉人の言葉が返ってくる体験は、汎用 AI チャットにはない「重み」と「物語」を持つ
- 相談が蓄積されるほど、より的を射た言葉が返るようになる（パーソナライズを課金理由に転換する）

### ターゲットユーザー

- 悩みや気持ちを書き出したいが、人には相談しづらい一般ユーザー
- 名言・格言で自己肯定感を得たいユーザー（Motto / Motivation 系の既存市場）

## 需要・競合調査 (2026-08-05 実測)

詳細は https://github.com/bannzai/IdeaMemo/issues/180#issuecomment-5188804189

- 励まし・名言の需要 (JP): Motto 4.6/8,787 件、Motivation 4.7/3,523 件 — 名言 × 自己肯定は成立市場
- 「聞いてもらう」需要 (JP): 話聞くよおじさん 4.7/1.8 万件 — 悩みを娯楽的に受け止めるアプリのヒット前例
- US: stoic. 4.8/3.5 万件 — 哲学 × ジャーナルのサブスクが成立している実証
- 直接競合 (JP): 語り部チャット 4.8/698 件（歴史学習・雑談寄り）。**「悩みを書くと適した偉人が選ばれて格言で返す」相談特化は空白**
- 脅威: Tolan 4.8/17.1 万件級の AI コンパニオン。汎用チャットに寄った瞬間この土俵に引きずり込まれるため、「返書」フォーマットを崩さない

## Shipaton 2026 戦略

提出締切 2026-09-30。狙う賞は **HAMM（主）+ Most Viral / Noise（副）**。

- HAMM: 相談チケット (consumable) + 聞き放題サブスクの 2 層に、「相談するたびにその偉人が図鑑に追加される」収集 × 課金の設計を重ねる
- Most Viral: 返書（偉人の肖像 + 格言 + ひとこと）の共有カードを拡散装置にする
- 審査対応: 審査員が試せるよう英語モード（Dear Socrates 形式）を用意する
- デイリー格言 push を入れる場合は OneSignal 賞にも接続できる（優先度は低）

## UI 要望（オーナー指定）

1. 幻想的な背景。怪しい占いアプリのような、星空が散りばめられた雰囲気（ダークテーマが正）
2. ファーストビューに「きょうのできごと・お悩み」を書く。ボタンを押すと回答を得られる
3. 該当する偉人がいたら、その偉人っぽいアバター（星座線アバター）を出してしゃべらせる
4. 該当することわざがあれば、できればその発祥の人をアバターで出現させてしゃべらせる
5. 該当人物がいなければ、図解カードでことわざ・格言の意味を丁寧に説明する
6. 出典・引用ははっきり出す。外国語由来のものは**原文を必ず併記**する
7. 日付ごとの悩み一覧で偉人の言葉を振り返られるようにする

デザイン依頼プロンプトの全文は [documents/design/claude-design-request.md](design/claude-design-request.md)。

## マネタイズ

- 無料: 1 日 1 通の返書
- 相談チケット ¥160/通（consumable。LLM 原価と連動する従量設計）
- 聞き放題サブスク ¥480〜730/月（相談履歴の蓄積による「あなた向け」精度向上を課金側に置く）
- 推し偉人テーマ・図鑑コンプリート要素（買い切り併売、フェーズ 2）
- 課金基盤は RevenueCat

## リスクと対策

1. **偽名言**: ネット流通の名言は誤帰属だらけで、LLM に生成させると捏造する。**出典付き名言 DB を自前で整備し、LLM の役割は「悩みへのマッチングと文脈づけ」に限定する**。DB は作り込むほど参入障壁になる
2. **メンタルヘルス隣接**: 「カウンセリング」「セラピー」「診断」を名乗らない・UI 文言に使わない（医療該当性と App Store 審査の両面）。希死念慮などの危機ワード検知 → 相談窓口への導線を初日から入れる
3. **著作権・パブリシティ**: 収録する偉人は死後 70 年経過に限定し、言葉はパブリックドメインの範囲で扱う。近現代の人物（松下幸之助、スティーブ・ジョブズ等）は初期は入れない
4. **LTV**: 悩みは毎日は発生しない。デイリー格言 push で常用文脈を作る（フェーズ 2）

## インフラ構成の決定

決定の経緯と詳細は [ADR 0001](adr/0001-ios-swiftui-firebase-functions-firestore.md)。

| 項目 | 決定 | 理由 |
|---|---|---|
| クライアント | SwiftUI (iOS 17+) | iOS 専用。星空演出・音声入力 (Speech) が素直に書ける。noodphoto / Focus の規約を流用 |
| バックエンド | Cloud Functions for Firebase (gen2, TypeScript) | LLM API キーの秘匿に必須。yomon で実績あり |
| DB | Cloud Firestore | 相談履歴のクラウド同期。書き込みは Functions 経由に限定 |
| 認証 | Firebase Authentication 匿名認証 | サインアップ画面なしで即利用開始。RevenueCat は匿名 UID と紐付け |
| Analytics | Firebase Analytics | 計測基盤 |
| 課金 | RevenueCat | consumable + サブスクの 2 層。Shipaton 要件 |
| LLM | 未確定（バックエンド実装 issue で ADR 化） | 候補: OpenAI（yomon ADR 0006 と同構成）/ Anthropic Claude |
| 法務ドキュメント公開 | GitHub Pages (docs/) | noodphoto / Focus と同じ構成。有効化は公開前チェックリストで行う |

## MVP スコープ

iOS 17+ を対象に:

1. ホーム: 星空背景 + 悩み入力（テキスト + 音声入力）
2. 返書生成: Functions が悩みを解析し、名言 DB から出典付きの格言・ことわざをマッチング、偉人の語りかけ形式で返書を生成
3. 返書表示: 星座線アバター（該当人物なしの場合は図解カード）+ 格言 + 出典・原文併記
4. 振り返り: 日付ごとの相談一覧
5. 偉人図鑑（星図): 相談を通じて出会った偉人が増えていく
6. 課金: 無料 1 日 1 通 + 相談チケット + サブスク（RevenueCat ペイウォール）
7. 共有カード: 星空 + 星座線アバター + 格言 + 出典の縦型カード（悩み本文は含めない）
8. セーフティ: 危機ワード検知 → 相談窓口への案内画面
9. 英語モード（Dear Socrates）: Shipaton 審査対応

### スコープ外（フェーズ 2 以降）

- 悩み以外への話題拡大・コーチング展開（汎用コンパニオン化は差別化を消すため受賞後に判断）
- デイリー格言 push（OneSignal 賞を狙う場合のみ）
- Android 展開
- 共有カードは MVP に含めるが、SNS 連携の凝った導線はフェーズ 2
