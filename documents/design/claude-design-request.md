# 偉言(イゲン) — Claude Design 依頼プロンプト

## アプリ概要
悩みや今日のできごとを書くと、それに適した偉人が現れて、出典付きの格言・ことわざで励ましてくれる iOS アプリ「偉言」。チャットではなく「人生相談への返書」フォーマット。カウンセリング・セラピーは名乗らない(励まし・自己肯定のエンタメ寄り)。

## 世界観・ブランド
- コンセプトは「幻想的で、ちょっと怪しい占いの館」。深い藍〜紫のグラデーションの星空が全画面の背景。金色の星、流れ星、うっすらした霧
- 偉人は**星座線アバター**で表現する: 夜空の星を点として、星座のように線で結んで偉人の姿が描かれる。全偉人でこの画風を統一する
- 神秘的だが読みやすさは犠牲にしない(格言・出典のテキストは高コントラストで)
- ダークテーマが正(星空なので実質ダーク固定)

## 画面一覧
1. **ファーストビュー(ホーム)**: 星空の中央に「きょうのできごと・お悩みをどうぞ」の入力エリア(テキスト+音声入力ボタン)。送信ボタンは「偉人に聞く」。余計なナビゲーションは置かず、書くことに集中させる
2. **回答演出 → 返書**: 送信すると星が集まり、星座線で偉人の姿が描き上がる演出 → 偉人が語りかける形で回答が表示される。回答の構成は: 悩みへのひとこと → 格言・ことわざ(大きく) → 意味と文脈の解説 → 励ましの結び
   - 該当する偉人がいる場合: その偉人の星座線アバターが話者になる
   - ことわざの場合: 発祥の人物が特定できればその人物のアバターが話者になる
   - **該当人物がいない場合: アバターの代わりに「図解カード」でことわざ・格言の意味をダイアグラムで丁寧に説明する**(この図解カードのフォーマットも星空世界観でデザインすること)
3. **出典表示(重要)**: すべての格言・ことわざに出典・引用元をはっきり表示する。**外国語由来のものは原文をそのまま併記し、日本語訳と並べる**(例: ラテン語の格言 → 原文+訳)。出典部分は装飾ではなく「信頼の根拠」として明確な情報ブロックにする
4. **振り返り**: 日付ごとの相談一覧(リスト or カレンダー)。過去の悩みと、もらった偉人の言葉を読み返せる。「あの日の自分への返書」を再訪する体験
5. **偉人図鑑(星図)**: 相談を通じて出会った偉人が、自分の夜空に星座として増えていく。未出会いは暗い星のみ。タップで偉人のプロフィールと過去にもらった言葉
6. **共有カード**: 星空+星座線アバター+格言+出典を1枚にした縦型カード。悩みの本文は含めない(格言と偉人だけをシェアできる)
7. **ペイウォール**: 無料=1日1通の返書。相談チケット(都度)+聞き放題サブスクの2層。RevenueCat Paywall を想定
8. **セーフティ**: 深刻な内容を検知した場合に表示する、相談窓口への案内画面(トーンは静かで誠実に。世界観は保ちつつ茶化さない)

## 主要コンポーネント
- 星座線アバター: 点(星)+細い光の線。登場時に線が描画されるアニメーション
- 返書カード: 巻物/手紙のメタファーは薄めに、星空に浮かぶ光のカードとして
- 図解カード: ことわざの構造(例え → 意味 → 使いどころ)を示すシンプルなダイアグラム
- 原文+訳の対訳ブロック

## モーション
- 星が集まって星座が描かれる登場演出、文字が星屑から現れる、図鑑で新しい星座が夜空に灯る
- 演出は初回リッチ・2回目以降は短縮できる設計に(毎日使うアプリのテンポを守る)

## 制約
- iOS(iPhone 縦持ち)。日本語 UI が第一言語だが、英語モード(US 向け「Dear Socrates」相当)を後続で載せるため、テキスト量が 1.5 倍になっても破綻しないレイアウトにすること
- 医療・診断を想起させる語(セラピー、カウンセリング、処方など)を UI 文言に使わない
