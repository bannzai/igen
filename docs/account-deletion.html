偉言（Dear Socrates）アカウントとデータ削除のご案内

偉言には、メールアドレスやパスワードを登録して作成するユーザーアカウントはありません。 アプリの初回起動時に、相談履歴や購入状態を管理するための匿名の利用者 ID が Firebase Authentication により自動的に発行されます。

現在の削除方法

現在、アプリ内に匿名の利用者 ID とサーバー上のデータを削除する機能はありません。 また、匿名の利用者 ID にはメールアドレスなどの連絡先が紐付いていないため、メールでお問い合わせいただいても対象のデータを特定できない場合があります。

アプリを端末から削除すると端末上のアプリデータは削除されますが、サーバーに保存された相談内容、返書、利用状況などは削除されません。 アプリを削除すると匿名の利用者 ID を失い、保存済みの相談履歴へアクセスできなくなることがあります。

お問い合わせ

アカウントやデータの取り扱いについてご不明な点は、 bannzai.app@gmail.com までお問い合わせください。相談内容の本文をメールに記載する必要はありません。

Account and data deletion instructions

Dear Socrates does not provide user accounts created with a registered email address or password. Firebase Authentication automatically issues an anonymous user ID when the app first launches to manage consultation history and purchase status.

The app currently does not provide a feature for deleting the anonymous user ID or its server-side data. Because no email address or other contact information is linked to that ID, we may be unable to identify the relevant data from an email inquiry.

Uninstalling the app deletes its on-device data but does not delete consultations, replies, usage records, or other data stored on the server. Uninstalling may also cause the anonymous user ID to be lost, preventing access to saved consultation history.

For questions about accounts or data handling, email bannzai.app@gmail.com. You do not need to include the text of your consultations in the email.
